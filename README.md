# pnipinp
PniPinPは動画とコメントを一緒にピクチャーインピクチャーで表示できる、ニコニコ動画向けの非公式Chrome拡張機能です。

### ダウンロード手順:
1. zip/tar.gzファイルをダウンロード
2. ダウンロードしたzip/tar.gzファイルを解凍

### インストール手順:
1. Chromeで "chrome://extesions" を開く
2. 右上の `デベロッパーモード` をオンにする
3. `パッケージ化されていない拡張機能を読み込む`をクリック
4. 解凍したフォルダー`pnipinp`を選択

### 使い方:
* 起動したいサイトで検索バー横の拡張機能ボタンを押して、PniPinPを選択することでピクチャーインピクチャーを起動できます。
* 閉じるときはタイトルバーの右上のボタン、あるいはコントロールバーの右下端のボタンで閉じることができます。
* PniPinPオプションから一部をカスタマイズすることができます。

# 注意点
* 非公式拡張機能です。
* ニコニコ動画以外のサイトで起動することもできますが、**動作を保証することはできません。**
* <font color="red">**現在、<mark>Youtube</mark>でピクチャーインピクチャーを起動することはできません。**</font>
